## ⚡ Что такое AgentWiki?

Каждый день инструменты вроде **Claude Code, Codex, Antigravity, OpenCode, Qoder, ZCode, Cline и DeepSeek** генерируют тысячи строк кода, исследуют сложные баги и принимают архитектурные решения. По умолчанию каждый агент сохраняет историю в собственных закрытых форматах и скрытых папках. Когда инструмент очищает кэш или когда вы переключаетесь на другого агента — драгоценный контекст и готовые решения бесследно теряются.

**AgentWiki** объединяет сессии всех ваших AI-агентов в единую, сверхбыструю и защищённую локальную базу знаний. Продукт поставляется в виде **одного компактного исполняемого файла без внешних зависимостей**, в который встроены:
1. **Настольное приложение (GUI)** на нативном движке ОС (без тяжелого Electron или встроенного Chromium).
2. **Долговременная память агентов через MCP** (инструменты `save_memory` и `list_snippets` позволяют Claude, Codex, Cursor и Antigravity помнить архитектуру проекта между сессиями).
3. **Мгновенный полнотекстовый поиск (FTS5 + Trigram)** по миллионам сообщений и изменений кода.
4. **База знаний и закладки решений** с фильтрацией по агентам, ролям, датам и подсветкой синтаксиса.
5. **Календарь активности и аналитика** (GitHub-style heatmap за год, активность по часам, распределение долей агентов).
6. **AI Blame и аудит авторства кода** (определение точной сессии, агента и промпта, написавшего конкретную строку файла).

## 🌟 Главные преимущества

### 🚀 100% Rust и один компактный бинарник (~3.8 МБ)
- **Ноль внешних зависимостей**: не требует установки Node.js, Python или системных библиотек.
- **Мгновенный старт** (< 20 мс) и минимальное потребление оперативной памяти (< 35 МБ).
- Кроссплатформенность: Windows (`agentwiki-app.exe`), macOS и Linux.

### 🤖 14+ встроенных адаптеров AI-агентов
Автоматически находит и индексирует сессии:
- **Anthropic Claude Code** (`~/.claude/projects`)
- **OpenAI Codex** (`~/.codex/sessions`)
- **Google Antigravity IDE и CLI (`agy`)** (`~/.gemini/antigravity` и `~/.gemini/antigravity-cli`)
- **OpenCode** (схемы **v1.x** SQLite/JSON и **v2.x** `session_v2`)
- **Qoder** (`AppData/Roaming/com.qoder.app.stable`)
- **ZCode** (`~/.zcode/cli`)
- **Cline, Roo Code, Kilo Code, Gajae Code** (`globalStorage`)
- **DeepSeek Harness** (`~/.dsh/sessions`)
- **Aider, Continue.dev, Hermes, GPT-me** и другие.

### 🧠 Долговременная память через Model Context Protocol (MCP)
Дайте вашим агентам возможность сохранять и вспоминать выводы между независимыми задачами:
- **`save_memory`**: агент фиксирует архитектурный инвариант, причину трудноуловимого бага или конфигурацию прямо в локальную базу AgentWiki.
- **`list_snippets`**: будущие сессии агентов мгновенно запрашивают сохранённые выводы с фильтром по языку программирования, тегам или роли (`assistant_memory`).

### 📊 Календарь активности и аналитика агентов
- **График активности в стиле GitHub**: 52-недельный календарь (heatmap) интенсивности работы.
- **Суточный ритм активности (24ч)**: распределение нагрузки по часам суток.
- **Доля агентов**: наглядный график популярности инструментов (Claude vs Codex vs Antigravity vs OpenCode).
- **Топ изменяемых файлов**: наиболее часто затрагиваемые файлы в истории проектов.

### 📌 Закладки и база знаний готовых решений
- Сохраняйте в один клик ключевые блоки кода, промпты и объяснения.
- Мульти-фильтры по инструменту, роли (`assistant_memory`, `user`, `assistant`, `tool`) и временным интервалам.
- 5 режимов сортировки (по дате добавления, дате сообщения, релевантности, названию, объёму).
- Мгновенный переход из закладки к нужному ходу в стенограмме исходной сессии.

### ↩️ История откатов и сжатия контекста (Rewound Turns)
- При превышении контекстного окна агенты часто отменяют шаги или сжимают контекст (compaction).
- AgentWiki сохраняет отменённые ходы с удобным переключателем **«↩ Отмененные»** в интерфейсе.

## 🚀 Быстрый старт

### 1. Скачайте готовый бинарник
Загрузите файл для вашей системы со страницы [Releases](https://github.com):
- **Windows**: `agentwiki-app.exe` (или консольная версия `agentwiki.exe`)
- **macOS / Linux**: `agentwiki-app` / `agentwiki`

*Установка не требуется — просто запустите файл двойным кликом!*

### 2. Запуск настольного приложения
```bash
./agentwiki-app
```
AgentWiki автоматически просканирует локальные диски, обнаружит все сессии AI-агентов, параллельно проиндексирует их и откроет нативное окно приложения.

### 3. Подключение через MCP (Claude Desktop, Cursor, Antigravity)
Добавьте AgentWiki в конфигурационный файл MCP (`claude_desktop_config.json` или `cursor.json`):
```json
{
  "mcpServers": {
    "agentwiki": {
      "command": "agentwiki",
      "args": ["mcp"]
    }
  }
}
```

Теперь ваши агенты могут обращаться к локальной памяти:
- `search_sessions(query)` — поиск решений по всем прошлым сессиям.
- `save_memory(title, content, tags)` — сохранение ключевых выводов и архитектуры.
- `list_snippets(role="assistant_memory")` — извлечение долговременной памяти.

## 💻 Команды консоли (CLI)

Помимо графического интерфейса, бинарник содержит полную мощь командной строки:

```bash
# Обзор дискового пространства, занятого сессиями агентов
agentwiki scan

# Мгновенный полнотекстовый поиск по всем разговорам
agentwiki search "JWT authentication with RS256"

# Поиск сессии, создавшей или изменившей файл
agentwiki trace src/auth/jwt.rs

# Аудит авторства строк с привязкой к сессиям AI
agentwiki blame src/auth/jwt.rs

# Запуск локального веб-сервера (опционально)
agentwiki web --port 7575

# Оптимизация индекса FTS5 и освобождение места на диске
agentwiki vacuum

# Диагностика и проверка доступных хранилищ агентов
agentwiki doctor
```

## 🔒 Приватность и архитектура

- **100% Локально**: Без телеметрии, без сбора данных, без облачных серверов. Ваши данные и код никогда не покидают компьютер.
- **SQLite с отображением в память (mmap)**: Чтение гигабайтных баз за микросекунды с нулевой нагрузкой на процессор.
- **Нативный системный WebView**: Использует системный WebView2 на Windows и WebKit на macOS/Linux, что обеспечивает микроскопический размер исполняемого файла (~3.8 МБ) и максимальную плавность интерфейса.
