## ⚡ Что такое AgentWiki-rs?

Каждый день инструменты вроде **Claude Code, Codex, Antigravity, OpenCode, Qoder, ZCode, Cline и DeepSeek** генерируют тысячи строк кода, исследуют сложные баги и принимают архитектурные решения. По умолчанию каждый агент сохраняет историю в собственных закрытых форматах и скрытых папках. Когда инструмент очищает кэш или когда вы переключаетесь на другого агента — драгоценный контекст и готовые решения бесследно теряются.

**AgentWiki-rs** объединяет сессии всех ваших AI-агентов в единую, сверхбыструю и защищённую локальную базу знаний. Продукт поставляется в виде **одного компактного исполняемого файла без внешних зависимостей**, в который встроены:
1. **Настольное приложение (GUI)** на нативном движке ОС (без тяжелого Electron или встроенного Chromium).
2. **Синхронизация в 1 клик и фоновая авто-синхронизация по расписанию** (кнопка `🔄 Sync` со спиннером и автообновление каждые 10 минут).
3. **⭐ Избранное (Favorites)** (быстрая отметка звёздочкой, фильтрация по чипу `⭐ Избранное (N)`, управление из UI, CLI и MCP).
4. **Долговременная память агентов через MCP** (инструменты `save_memory` и `list_snippets` позволяют Claude, Codex, Cursor и Antigravity помнить архитектуру проекта между сессиями).
5. **Мгновенный полнотекстовый поиск (FTS5 + Trigram)** по миллионам сообщений и изменений кода.
6. **База знаний и закладки решений** с фильтрацией по агентам, ролям, датам и подсветкой синтаксиса.
7. **Календарь активности и аналитика** (GitHub-style heatmap за год, активность по часам, распределение долей агентов).
8. **AI Blame и аудит авторства кода** (определение точной сессии, агента и промпта, написавшего конкретную строку файла).

## 🌟 Главные преимущества

### 🚀 100% Rust и один компактный бинарник (~3.8 МБ)
- **Ноль внешних зависимостей**: не требует установки Node.js, Python или системных библиотек.
- **Мгновенный старт** (< 20 мс) и минимальное потребление оперативной памяти (< 35 МБ).
- Кроссплатформенность: Windows (`agentwiki-app.exe`), macOS и Linux.

### 🔄 Ручная синхронизация и авто-синхронизация по расписанию
- **Синхронизация по кнопке (`🔄 Синхронизация`)**: расположена прямо над списком сессий, показывает анимацию вращения и точное время последнего обновления (`Синхронизировано HH:MM`).
- **Фоновая авто-синхронизация (`Авто-синхронизация (10м)`)**: автоматический опрос хранилищ каждые 10 минут, подтягивающий свежие диалоги агентов прямо во время работы без перезагрузки приложения.
- **Сохранение состояния**: включение авто-синхронизации и таймштамп сохраняются в `localStorage`.

### ⭐ Избранные сессии (Favorites)
- **Отметка в один клик (`⭐`)**: добавляйте в избранное ключевые архитектурные сессии, сложные багфиксы или удачные промпты.
- **Быстрый фильтр-чип**: мгновенная фильтрация по клику на `⭐ Избранное (N)` в боковой панели без необходимости ввода текста.
- **Контекстное меню, CLI и MCP**: управление через правый клик мыши, отдельная команда консоли (`agentwiki favorites`) и инструмент MCP (`list_favorites`).

### 🤖 14+ встроенных адаптеров AI-агентов
Автоматически находит и индексирует сессии:
- **Anthropic Claude Code** (`~/.claude/projects`)
- **OpenAI Codex** (`~/.codex/sessions` и `thread_history_1.sqlite`)
- **Google Antigravity IDE и CLI (`agy`)** (`~/.gemini/antigravity` и `~/.gemini/antigravity-cli`)
- **OpenCode** (схемы **v1.x** SQLite/JSON и **v2.x** `session_v2`)
- **Qoder** (`AppData/Roaming/com.qoder.app.stable`)
- **ZCode** (`~/.zcode/cli`)
- **Cline, Roo Code, Kilo Code, Gajae Code** (`globalStorage`)
- **DeepSeek Harness** (`~/.dsh/sessions`)
- **Aider, Continue.dev, Hermes, Kimi, GPT-me** и другие.

### 🧠 Долговременная память через Model Context Protocol (MCP)
Дайте вашим агентам возможность сохранять и вспоминать выводы между независимыми задачами:
- **`save_memory`**: агент фиксирует архитектурный инвариант, причину трудноуловимого бага или конфигурацию прямо в локальную базу AgentWiki-rs.
- **`list_snippets`**: будущие сессии агентов мгновенно запрашивают сохранённые выводы с фильтром по языку программирования, тегам или роли (`assistant_memory`).
- **`list_favorites`**: агенты могут запросить список эталонных избранных сессий для точного контекста.

### 📊 Календарь активности и аналитика агентов
- **График активности в стиле GitHub**: 52-недельный календарь (heatmap) интенсивности работы с полной поддержкой тёмной темы.
- **Суточный ритм активности (24ч)**: распределение нагрузки по часам суток.
- **Доля агентов**: наглядный график популярности инструментов (Claude vs Codex vs Antigravity vs OpenCode).
- **Топ изменяемых файлов**: наиболее часто затрагиваемые файлы в истории проектов.

### 📌 Закладки и база знаний готовых решений
- Сохраняйте в один клик ключевые блоки кода, промпты и объяснения.
- Мульти-фильтры по инструменту, роли (`assistant_memory`, `user`, `assistant`, `tool`) и временным интервалам.
- 5 режимов сортировки (по дате добавления, дате сообщения, релевантности, названию, объёму).
- Мгновенный переход из закладки к нужному ходу в стенограмме исходной сессии.

### ↩️ История откатов и сжатия контекста (Rewound Turns)
- При превышении контекстного окна агенты часто отменяют шаги или сжимают контекст (compaction).
- AgentWiki-rs сохраняет отменённые ходы с удобным переключателем **«↩ Отмененные»** в интерфейсе.

## 🚀 Быстрый старт

### 1. Скачайте готовый бинарник
Загрузите файл для вашей системы со страницы [Releases](https://github.com/AlexZander85/AgentWiki-rs):
- **Windows**: `agentwiki-app.exe` (или консольная версия `agentwiki.exe`)
- **macOS / Linux**: `agentwiki-app` / `agentwiki`

*Установка не требуется — просто запустите файл двойным кликом!*

### 2. Запуск настольного приложения
```bash
./agentwiki-app
```
AgentWiki-rs автоматически просканирует локальные диски, обнаружит все сессии AI-агентов, параллельно проиндексирует их и откроет нативное окно приложения.

### 3. Подключение через MCP (Claude Desktop, Cursor, Antigravity)
Добавьте AgentWiki-rs в конфигурационный файл MCP (`claude_desktop_config.json` или `cursor.json`):
```json
{
  "mcpServers": {
    "agentwiki": {
      "command": "agentwiki",
      "args": ["mcp"]
    }
  }
}
```

Теперь ваши агенты могут обращаться к локальной памяти:
- `search_sessions(query)` — поиск решений по всем прошлым сессиям.
- `save_memory(title, content, tags)` — сохранение ключевых выводов и архитектуры.
- `list_snippets(role="assistant_memory")` — извлечение долговременной памяти.
- `list_favorites()` — получение списка избранных сессий.

## 💻 Команды консоли (CLI)

Помимо графического интерфейса, бинарник содержит полную мощь командной строки:

```bash
# Обзор дискового пространства, занятого сессиями агентов
agentwiki scan

# Ручной запуск синхронизации всех хранилищ
agentwiki sync

# Просмотр избранных сессий
agentwiki favorites --json

# Мгновенный полнотекстовый поиск по всем разговорам
agentwiki search "JWT authentication with RS256"

# Поиск сессии, создавшей или изменившей файл
agentwiki trace src/auth/jwt.rs

# Аудит авторства строк с привязкой к сессиям AI
agentwiki blame src/auth/jwt.rs

# Запуск локального веб-сервера (опционально)
agentwiki web --port 7575

# Оптимизация индекса FTS5 и освобождение места на диске
agentwiki vacuum

# Диагностика и проверка доступных хранилищ агентов
agentwiki doctor
```

## 🏛️ Архитектура высокой производительности: почему нативный WebView ОС?

AgentWiki-rs обеспечивает мгновенный отклик интерфейса при микроскопическом размере бинарника (~3.8 МБ) и скромном потреблении памяти (~35 МБ RAM) за счёт оптимального разделения обязанностей между Rust и операционной системой:

### 1. Нативный WebView операционной системы без тяжелого Electron (`wry` + `tao`)
- **Никаких встроенных Chromium и Node.js**: В отличие от приложений на Electron (которые весят 120–180 МБ и забирают от 200 МБ RAM на старте), AgentWiki-rs задействует встроенный системный веб-движок ОС:
  - **Windows**: Системный Microsoft Edge WebView2 (предустановлен в Windows 10/11, аппаратное ускорение DirectComposition).
  - **macOS**: Нативный Apple WebKit (`WKWebView` с ускорением Metal на Apple Silicon M-серии и Intel).
  - **Linux**: Системный WebKitGTK (`libwebkit2gtk-4.1`).
- **Идеальная нативная типографика**: Субпиксельное сглаживание шрифтов ОС, поддержка лигатур кода (`Fira Code`, `JetBrains Mono`), системные эмодзи и идеальное масштабирование на экранах с высоким DPI.
- **Чистый режим CLI / MCP**: При вызове из терминала (`agentwiki search`) или через протокол MCP агентами графический движок даже не инициализируется — программа работает как чистый ассемблерный бинарник на Rust с расходом ~10 МБ RAM.

### 2. Клиентский рендеринг Markdown с ленивой загрузкой против серверного HTML
Почему Markdown парсится через `markdown-it` в WebView, а не компилируется в HTML на стороне сервера в Rust?
- **В 3–5 раз меньший объем данных**: Rust отдает компактный сырой текст напрямую из базы SQLite через `mmap`. Пре-генерация HTML на сервере раздула бы JSON с 150 КБ до 2.5 МБ из-за тысяч тегов `<pre>`, `<code>` и сотен раскрашенных `<span>`, убивая скорость сериализации и IPC-трафика.
- **Мгновенное открытие через `IntersectionObserver`**: При открытии сессии на 500+ сообщений мгновенно рендерятся только первые 30 видимых сообщений (< 15 мс). Остальные сообщения парсятся «на лету» только тогда, когда пользователь докручивает до них скроллом, полностью исключая зависания интерфейса (DOM thrashing).
- **Интерактивность без потерь**: Подсветка найденных слов поиска (`<mark>`), кнопки копирования кода в один клик, сворачивание вызовов инструментов и точное копирование «Copy as Markdown» выполняются безопасно внутри DOM-дерева без риска повредить синтаксис HTML-сущностей сервера.
